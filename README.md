# JOFLIX

App do JOFLIX para TV (Android TV, Google TV, Fire TV Stick e TV box Android).

- Baixar a versão mais nova: [JOFLIX.apk](https://github.com/joandersonandrade/joflix-tv/releases/latest/download/JOFLIX.apk)
- As TVs com o JOFLIX procuram atualização sozinhas (arquivo `versao.json` da versão mais nova).

Suporte pelo WhatsApp que aparece no próprio app.
